# Laws & Effects

A curated reference website: a centralized directory of mental models, systemic rules, and psychological quirks. A play on "cause and effect" — mapping the hidden rules of systems and the quirks of human nature.

## Features

- Single-page, mobile-responsive **micro-card grid** with dual-axis filtering — zero page reloads.
- Real-time fuzzy search in a fixed header.
- **Type axis:** Laws, Effects, Principles, Concepts.
- **Domain axis:** Mind & Behavior, Systems & Tech, Politics & Society, Science & Physics, Media & Society, Philosophy & Logic.
- Each card: color-coded #Type and #Domain tags → bold title → concise definition → "Authoritative Source →" external link.
- WCAG 2.2 AA: all color pairs verified for contrast, skip link, visible focus rings, aria-live result count, labeled controls.

## Running

Open `index.html` in a browser. There is no build step and no dependencies.

## Editing

The full entry database is the `ENTRIES` array inside `index.html`. See `AGENTS.md` for content and styling conventions (including how to add entries and the WCAG requirements).
